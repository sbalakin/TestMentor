# Система управления менторами "Koi"

## Описание проекта
Веб-приложение для управления работой с менторами: учет выполненных работ, расчет выплат, генерация актов выполненных работ в формате PDF.

## Возможности
- ✅ **Управление менторами**: создание, редактирование, просмотр профилей
- ✅ **Учет работы**: добавление записей о выполненных работах с указанием часов
- ✅ **Автоматический расчет**: расчет стоимости работ (часы × ставка)
- ✅ **Фильтрация и поиск**: по менторам, датам, категориям
- ✅ **Статистика**: дашборд с основными метриками
- ✅ **Экспорт/Импорт**: сохранение и восстановление данных
- ⏳ **Генерация актов**: формирование PDF отчетов (в разработке)

## Архитектура

### Модульный монолит + Clean Architecture
Проект построен на модульной монолитной архитектуре, где каждый модуль - это независимая фича со своей Clean Architecture внутри.

**Преимущества**:
- 🔄 Каждый модуль можно легко выделить в микросервис
- 🧩 Независимые модули с четкими границами
- 📦 Легкое тестирование отдельных модулей
- 🔌 Event-driven коммуникация между модулями

## Модули системы

### 1. Mentors (Менторы)
Управление профилями менторов.

**Основные сценарии**:
- Создание ментора (ФИО, email, специализация, ставка)
- Просмотр всех менторов
- Фильтрация по статусу
- Поиск по имени/email

**Статус**: ✅ Реализовано (базовая функциональность)

### 2. Work Records (Записи о работе)
Учет выполненной работы менторов.

**Основные сценарии**:
- Добавление записи (ментор, дата, часы, описание)
- Просмотр всех записей
- Фильтрация (по ментору, месяцу, категории)
- Автоматический расчет стоимости

**Статус**: ✅ Реализовано (базовая функциональность)

### 3. Reports (Отчеты)
Генерация актов выполненных работ.

**Планируемые сценарии**:
- Выбор ментора и периода
- Генерация PDF акта
- Сохранение в архив
- Скачивание и отправка на email

**Статус**: ⏳ В разработке

### 4. Statistics (Статистика)
Отображение ключевых метрик.

**Реализованные метрики**:
- Общее количество менторов
- Количество активных менторов
- Часы за текущий месяц
- Сумма к выплате за месяц

**Статус**: ✅ Реализовано (базовая функциональность)

### 5. Settings (Настройки)
Управление системой и данными.

**Реализованные функции**:
- Экспорт всех данных в JSON
- Импорт данных из JSON
- Очистка всех данных
- Информация о хранилище

**Статус**: ✅ Реализовано

### 6. Export (Экспорт)
Экспорт данных в различные форматы.

**Планируемые форматы**:
- Excel (XLSX)
- CSV
- PDF

**Статус**: ⏳ Планируется

## Принципы работы

### Event-Driven коммуникация
Модули не знают друг о друге и общаются только через события:

```javascript
// Модуль Mentors публикует событие
eventBus.publish('mentor:created', {
  mentorId: '123',
  fullName: 'Иванов Иван'
});

// Модуль Statistics подписан на событие
eventBus.subscribe('mentor:created', (data) => {
  // Обновить статистику
});
```

### Clean Architecture в каждом модуле

```
Domain (Бизнес-логика)
  ↑
Application (Use Cases)
  ↑
Infrastructure (Реализация)
  ↓
Presentation (UI)
```

**Правило зависимостей**: Внутренние слои не зависят от внешних.

## Разработка

### Добавление нового модуля

1. **Создать структуру**:
```bash
frontend/modules/new-module/
├── module.js                 # Точка входа
├── README.md                 # Документация
├── domain/
│   ├── entities/
│   ├── value-objects/
│   └── repositories/
├── application/
│   └── use-cases/
├── infrastructure/
│   └── repositories/
└── presentation/
    ├── pages/
    ├── controllers/
    └── styles/
```

2. **Зарегистрировать в core/app.js**:
```javascript
const moduleNames = [
  'mentors',
  'work-records',
  'new-module'  // Добавить сюда
];
```

3. **Создать module.js**:
```javascript
export default {
  name: 'new-module',
  async init(app) {
    // Инициализация модуля
  }
};
```
