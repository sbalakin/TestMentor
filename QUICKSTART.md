# Быстрый старт 🚀

Это руководство поможет вам запустить систему управления менторами за 5 минут.

## Шаг 1: Проверка требований ✅

Убедитесь, что у вас есть:
- ✅ Современный браузер (Chrome 90+, Firefox 88+, Safari 14+)
- ✅ Возможность открывать HTML файлы (или локальный веб-сервер)

## Шаг 2: Запуск приложения 🎯

### Вариант А: Прямое открытие (самый простой)

1. Откройте папку проекта
2. Перейдите в `frontend/`
3. Откройте `index.html` в браузере

```bash
# MacOS
open frontend/index.html

# Linux
xdg-open frontend/index.html

# Windows
start frontend/index.html
```

**⚠️ Внимание**: Некоторые браузеры блокируют ES6 модули при прямом открытии файлов из-за политики CORS. Если увидите ошибки в консоли, используйте Вариант Б.

### Вариант Б: С локальным сервером (рекомендуется)

#### Используя Python (встроен в MacOS/Linux):
```bash
cd frontend
python3 -m http.server 8000
```

Откройте: http://localhost:8000

#### Используя npx (если установлен Node.js):
```bash
npx serve frontend
```

Откройте указанный URL (обычно http://localhost:3000)

#### Используя PHP (если установлен):
```bash
cd frontend
php -S localhost:8000
```

Откройте: http://localhost:8000

## Советы и хитрости 💡

### Экспорт данных для резервного копирования

```
Настройки → Экспортировать данные
```

Скачается JSON файл с именем вроде `mentor-system-backup-2025-10-31.json`

Храните его в безопасном месте!

### Импорт данных после переустановки

```
Настройки → Импортировать данные → Выбрать файл
```

**⚠️ Внимание**: Импорт заменит все текущие данные!

### Очистка данных для нового начала

```
Настройки → Очистить все данные
```

**⚠️ Внимание**: Данные будут удалены безвозвратно! Сделайте экспорт перед очисткой.

### Просмотр использования хранилища

```
Настройки → Хранилище
```

Увидите:
- Использовано (в KB)
- Процент заполнения

LocalStorage имеет лимит ~5MB.

## Решение проблем 🔧

### Ошибка "Cannot use import statement outside a module"

**Решение**: Используйте локальный веб-сервер (Вариант Б)

### Данные не сохраняются

**Возможные причины**:
1. Переполнен LocalStorage
   - **Решение**: Экспортируйте данные, очистите хранилище
2. Приватный режим браузера
   - **Решение**: Используйте обычный режим

### Страница не загружается

**Проверьте**:
1. Консоль браузера (F12) на наличие ошибок
2. Правильность пути к файлам
3. Версию браузера

### Не работают фильтры

**Решение**: Обновите страницу (F5 или Cmd+R)
