# 🌙 Темная тема KOI

## ✨ Что реализовано

Добавлена полноценная система темной/светлой темы с плавными переходами и современным дизайном.

### Основные возможности:
- 🌙 **Темная тема по умолчанию** - загружается автоматически при первом открытии
- ☀️ **Светлая тема** - можно переключиться в любой момент
- 💾 **Сохранение выбора** - тема сохраняется в localStorage
- 🎨 **CSS переменные** - легко кастомизировать цвета
- 🔄 **Плавные переходы** - все изменения с анимацией
- 🔘 **Кнопка переключения** - плавающая кнопка в правом нижнем углу

## 🔧 Как использовать

### Автоматическое подключение (уже сделано на всех страницах):

```html
<!-- В <head> -->
<link rel="stylesheet" href="/core/shared/theme.css">

<!-- Перед </body> -->
<script src="/core/shared/theme.js"></script>
<script>
    document.addEventListener('DOMContentLoaded', () => {
        window.themeManager.createToggleButton();
    });
</script>
```

### Программное управление темой:

```javascript
// Переключить тему
window.themeManager.toggle();

// Установить конкретную тему
window.themeManager.setTheme('dark');  // или 'light'

// Получить текущую тему
const currentTheme = window.themeManager.getCurrentTheme();
console.log(currentTheme); // 'dark' или 'light'
```

## 🎯 Кнопка переключения темы

Кнопка автоматически появляется в правом нижнем углу экрана:
- **🌙** - когда активна темная тема (нажать для переключения на светлую)
- **☀️** - когда активна светлая тема (нажать для переключения на темную)

### Стиль кнопки:
- Круглая плавающая кнопка с градиентом
- Зафиксирована в правом нижнем углу
- Эффект подъема при наведении
- z-index: 9999 (всегда сверху)

## 🛠️ Кастомизация

### Изменение цветов темной темы:

Отредактируйте `theme.css`:

```css
[data-theme="dark"] {
    --color-primary: #7c3aed;      /* Основной акцент */
    --bg-primary: #0f172a;          /* Фон страницы */
    --bg-secondary: #1e293b;        /* Фон карточек */
    --text-primary: #f1f5f9;        /* Основной текст */
    /* ... остальные переменные ... */
}
```

### Изменение анимаций:

```css
* {
    transition-duration: 0.3s;      /* Скорость перехода */
    transition-timing-function: ease; /* Тип анимации */
}
```

## 💡 Советы

1. **Для добавления темы на новую страницу:**
   - Подключите `theme.css` в `<head>`
   - Добавьте скрипт `theme.js` перед `</body>`
   - Вызовите `createToggleButton()` в DOMContentLoaded

2. **Для изменения темы по умолчанию:**
   - Отредактируйте `theme.js`, строку:
     ```javascript
     const savedTheme = localStorage.getItem(this.THEME_KEY) || this.DARK;
     ```
   - Замените `this.DARK` на `this.LIGHT`

3. **Для добавления новых цветов:**
   - Добавьте CSS переменную в `:root` и `[data-theme="dark"]`
   - Используйте её в стилях: `color: var(--your-new-color);`
