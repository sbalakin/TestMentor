# Frontend - Система управления менторами

## Описание
Frontend приложение для управления менторами, их работой и генерации отчетов. Реализовано с использованием модульной монолитной архитектуры с Clean Architecture внутри каждого модуля.

## Технологии
- **HTML5** - разметка страниц
- **CSS3** - стилизация (CSS Variables, Grid, Flexbox)
- **JavaScript (ES6+)** - логика приложения (модули, async/await, классы)
- **LocalStorage** - хранение данных
- **Event Bus** - межмодульная коммуникация

## Архитектура

### Модульный монолит
Приложение разделено на независимые модули, каждый из которых представляет собой отдельную бизнес-фичу с полной Clean Architecture внутри.

```
frontend/
├── core/                    # Ядро системы
│   ├── app.js              # Точка входа, инициализация модулей
│   ├── events/             # Event Bus для связи модулей
│   │   └── event-bus.js
│   └── shared/             # Общие утилиты
│       ├── storage.js      # Работа с LocalStorage
│       ├── validators.js   # Валидаторы
│       └── formatters.js   # Форматирование данных
│
├── modules/                 # Модули (фичи)
│   ├── mentors/            # Управление менторами
│   ├── work-records/       # Записи о работе
│   ├── reports/            # Отчеты и акты
│   ├── statistics/         # Статистика
│   ├── settings/           # Настройки
│   └── export/             # Экспорт данных
│
├── assets/                  # Статичные ресурсы
│   └── styles/             # Глобальные стили
│       └── main.css
│
└── index.html              # Главная страница (дашборд)
```

### Структура модуля (Clean Architecture)
Каждый модуль имеет одинаковую структуру:

```
modules/[module-name]/
├── module.js               # Точка входа модуля
├── README.md               # Документация модуля
│
├── domain/                 # Бизнес-логика
│   ├── entities/           # Сущности с логикой
│   ├── value-objects/      # Неизменяемые значения
│   ├── repositories/       # Интерфейсы репозиториев
│   └── services/           # Доменные сервисы
│
├── application/            # Use Cases
│   ├── use-cases/          # Сценарии использования
│   ├── dto/                # Объекты передачи данных
│   └── events/             # События модуля
│
├── infrastructure/         # Реализация
│   ├── repositories/       # Реализация репозиториев
│   └── storage/            # Работа с хранилищем
│
└── presentation/           # UI
    ├── pages/              # HTML страницы
    ├── controllers/        # Контроллеры страниц
    ├── components/         # UI компоненты
    └── styles/             # CSS модуля
```

## Модули

### 1. Mentors (Менторы)
**Ответственность**: Управление профилями менторов

**Функционал**:
- ✅ Создание ментора
- ✅ Просмотр списка менторов
- ✅ Фильтрация и поиск
- ⏳ Редактирование ментора
- ⏳ Удаление ментора
- ⏳ Детальный профиль

**События**: `mentor:created`, `mentor:updated`, `mentor:deleted`

### 2. Work Records (Записи о работе)
**Ответственность**: Учет выполненной работы

**Функционал**:
- ✅ Добавление записи о работе
- ✅ Просмотр всех записей
- ✅ Фильтрация (по ментору, месяцу, категории)
- ✅ Автоматический расчет стоимости
- ✅ Статистика
- ⏳ Редактирование записи
- ⏳ Удаление записи

**События**: `work:added`, `work:updated`, `work:deleted`

### 3. Reports (Отчеты)
**Ответственность**: Генерация актов выполненных работ

**Функционал**:
- ⏳ Генерация PDF актов
- ⏳ Архив актов
- ⏳ Просмотр актов
- ⏳ Скачивание актов
- ⏳ Отправка на email

**События**: `report:generated`, `report:downloaded`

### 4. Statistics (Статистика)
**Ответственность**: Отображение статистики и аналитики

**Функционал**:
- ✅ Дашборд с основными метриками
- ⏳ Графики по периодам
- ⏳ Статистика по менторам
- ⏳ Экспорт статистики

**События**: Подписан на все события для обновления

### 5. Settings (Настройки)
**Ответственность**: Настройки системы

**Функционал**:
- ✅ Экспорт данных (JSON)
- ✅ Импорт данных (JSON)
- ✅ Очистка данных
- ✅ Информация о хранилище
- ⏳ Настройка валюты
- ⏳ Настройка формата дат

### 6. Export (Экспорт)
**Ответственность**: Экспорт данных в различные форматы

**Функционал**:
- ⏳ Экспорт в Excel
- ⏳ Экспорт в CSV
- ⏳ Экспорт в PDF

## Принципы взаимодействия

### Event-Driven Architecture
Модули общаются только через Event Bus:

```javascript
// Публикация события
eventBus.publish('mentor:created', {
  mentorId: '123',
  fullName: 'Иван Иванов'
});

// Подписка на событие
eventBus.subscribe('mentor:created', (data) => {
  console.log('New mentor:', data.fullName);
});
```

### Правила
1. ❌ **НЕТ** прямых импортов между модулями
2. ❌ **НЕТ** прямых вызовов use cases других модулей
3. ✅ **ДА** общие утилиты из `core/shared`
4. ✅ **ДА** Event Bus для коммуникации

## Хранение данных

### LocalStorage Keys
- `mentor_system_mentors` - список менторов
- `mentor_system_work_records` - записи о работе
- `mentor_system_reports` - сформированные отчеты
- `mentor_system_settings` - настройки системы

## Стилизация

### CSS Variables
Все цвета, отступы, шрифты вынесены в CSS Variables в `assets/styles/main.css`

```css
:root {
  --color-primary: #2563EB;
  --spacing-md: 16px;
  --font-size-base: 14px;
  /* и т.д. */
}
```

### Адаптивность
- Desktop-first подход
- Breakpoint: 768px для мобильных

## Контрибьюторам

### Добавление нового модуля
1. Создайте структуру модуля по шаблону
2. Создайте `module.js` с методом `init()`
3. Добавьте модуль в `core/app.js` в список `moduleNames`
4. Создайте `README.md` с документацией
5. Реализуйте слои по Clean Architecture

### Правила кода
- ESLint (будет настроен)
- JSDoc комментарии для публичных методов
- Async/await вместо промисов
- Деструктуризация и spread operator
- Arrow functions
