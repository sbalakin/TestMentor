# Архитектура фронтенда KOI

## 🏗️ Общая структура

Фронтенд разделен на **два независимых приложения**:

1. **Админ-панель** (`/admin-panel/`) - для руководителей (MANAGER)
2. **Личный кабинет ментора** (`/mentor-cabinet/`) - для менторов (MENTOR)

```

│   ├── index.html             # Главный дашборд
```

## 🔐 Логика авторизации

### 1. Единая точка входа

**`/login.html`** - единая страница входа для всех пользователей

После успешной авторизации:
- **MANAGER** → перенаправляется на `/admin-panel/index.html`
- **MENTOR** → перенаправляется на `/mentor-cabinet/index.html`

### 2. Защита страниц

Каждая страница проверяет:
1. **Авторизован ли пользователь** - если нет, редирект на `/login.html`
2. **Соответствует ли роль** - если нет, редирект на правильное приложение

```javascript
// Пример защиты админ-панели
if (!authService.isAuthenticated()) {
    window.location.href = '/login.html';
} else if (!authService.isManager()) {
    window.location.href = '/mentor-cabinet/index.html';
}
```

## 👔 Админ-панель (MANAGER)

### Главная страница: `/admin-panel/index.html`

**Функционал:**
- Статистика (всего менторов, активных, часы, сумма)
- Поиск и фильтры
- Таблица всех менторов
- Действия: просмотр, редактирование, удаление

### Страницы админ-панели:

#### 📋 Менторы
- **`/admin-panel/pages/mentors/list.html`** - список всех менторов с карточками
- **`/admin-panel/pages/mentors/create.html`** - форма создания ментора
- **`/admin-panel/pages/mentors/view.html`** - детальный профиль ментора

#### 📝 Записи работ
- **`/admin-panel/pages/works/list.html`** - список всех записей от всех менторов

#### 📊 Отчеты
- **`/admin-panel/pages/reports/list.html`** - архив сформированных отчетов (в разработке)

#### ⚙️ Настройки
- **`/admin-panel/pages/settings/index.html`** - настройки системы, экспорт/импорт

### Доступ руководителя:
✅ Видит **ВСЕХ** менторов (30 шт)  
✅ Видит **ВСЕ** записи о работе (100 шт)  
✅ Может создавать/редактировать/удалять менторов  
✅ Может добавлять работы для любого ментора  
✅ Доступны все настройки и отчеты

## 🎓 Личный кабинет ментора (MENTOR)

### Главная страница: `/mentor-cabinet/index.html`

**Функционал:**
- Профиль ментора с аватаром
- Быстрая статистика (записей, часов, заработано, часов в месяце)
- Последние записи о работе
- Быстрые действия (добавить работу, мои записи, профиль)

### Страницы ЛК ментора:

#### 📝 Мои записи
- **`/mentor-cabinet/pages/my-works.html`** - все записи о работе ментора
  - Фильтры по месяцу и категории
  - Удаление своих записей

#### ➕ Добавить работу
- **`/mentor-cabinet/pages/add-work.html`** - форма добавления записи о работе
  - Автоматический расчет суммы
  - Ограничение по дате (только прошлое)

#### 👤 Мой профиль
- **`/mentor-cabinet/pages/my-profile.html`** - детальная информация о менторе
  - Контактные данные
  - Рабочая информация
  - Статистика

### Доступ ментора:
✅ Видит ТОЛЬКО СВОЙ профиль  
✅ Видит ТОЛЬКО СВОИ записи о работе  
✅ Может добавлять ТОЛЬКО СВОИ работы  
❌ НЕ может видеть других менторов  
❌ НЕ может создавать/удалять менторов  
❌ НЕ может видеть админ-панель

## 🔧 Общие модули (shared)

### Core (`/core/`)
- **app.js** - инициализация, регистрация модулей
- **event-bus.js** - pub/sub для межмодульной связи
- **api.js** - HTTP клиент с автоматической передачей JWT
- **storage.js** - LocalStorage wrapper
- **validators.js** - валидация данных
- **formatters.js** - форматирование (деньги, даты)
- **utils.js** - утилиты
- **ui-kit.js** - переиспользуемые UI компоненты

### Modules (`/modules/`)
Каждый модуль следует Clean Architecture:

```
module-name/
├── domain/               # Бизнес-логика
│   ├── entities/
│   ├── value-objects/
│   ├── repositories/
│   └── services/
├── application/          # Use cases
│   ├── use-cases/
│   ├── dto/
│   └── events/
├── infrastructure/       # Реализация
│   ├── repositories/
│   └── storage/
└── presentation/         # UI
    ├── pages/
    ├── controllers/
    ├── components/
    └── styles/
```

## 🚀 Запуск

1. **Запустить бэкенд:**
```bash
cd backend
source venv/bin/activate
python main.py
```

2. **Запустить фронтенд:**
```bash
# В корне проекта
python -m http.server 8000
```

3. **Открыть в браузере:**
```
http://localhost:8000/login.html
```

4. **Тестовые аккаунты:**
- **Руководитель:** `admin` / `admin123`
- **Ментор:** `mentor1` / `mentor1123`

## 🎯 Преимущества разделения

### 1. **Независимость**
- Два приложения работают независимо
- Разные интерфейсы под разные роли
- Легко развивать отдельно

### 2. **Безопасность**
- Ментор физически не может попасть в админ-панель
- Каждое приложение защищено на уровне роутинга
- Минимальная утечка информации

### 3. **UX**
- Каждая роль видит только нужный функционал
- Простая навигация без лишних пунктов меню
- Оптимизированный интерфейс под задачи

### 4. **Масштабируемость**
- Легко добавить новые роли (например, бухгалтер)
- Можно выделить приложения на разные домены
- Простая интеграция новых модулей

- **Страницы:** `kebab-case.html` (example: `my-works.html`)

- **Абсолютные пути:** всегда используем `/` в начале

## 🔄 Workflow разработки

### Добавление новой страницы в админ-панель:

1. Создать HTML в `/admin-panel/pages/`
2. Добавить защиту роли (MANAGER)
3. Обновить навигацию
4. Добавить ссылку в дашборд

### Добавление новой страницы в ЛК ментора:

1. Создать HTML в `/mentor-cabinet/pages/`
2. Добавить защиту роли (MENTOR)
3. Обновить навигацию
4. Добавить ссылку на главную

### Добавление нового модуля:

1. Создать структуру в `/modules/new-module/`
2. Реализовать слои: domain → application → infrastructure → presentation
3. Зарегистрировать в `/core/app.js`
4. Использовать в приложениях
