# Дизайн и UI/UX требования

## 1. Общая концепция дизайна

### Стиль
- **Современный минималистичный дизайн**
- Чистые линии, достаточно воздуха между элементами
- Профессиональный business-стиль
- Функциональность важнее декоративности

### Принципы дизайна
1. **Простота** - интуитивно понятный интерфейс
2. **Консистентность** - единообразие элементов на всех страницах
3. **Иерархия** - четкое выделение важных элементов
4. **Обратная связь** - реакция на действия пользователя
5. **Доступность** - читаемость, контрастность

**Secondary Button (Вторичная кнопка)**

## 8. Анимации и переходы

### Transitions (Переходы)
**Стандартное время**: 200ms
**Easing**: ease-in-out

**Применение**:
- Hover состояния: 150ms
- Focus состояния: 200ms
- Модальные окна: 300ms
- Уведомления: 250ms

### Animations (Анимации)
- Fade in: opacity 0 → 1
- Slide in: transform translateY(20px) → 0
- Spin (для loader): rotate 360deg

### Микроанимации
- Кнопки: легкое увеличение scale при hover
- Карточки: увеличение тени при hover
- Успешное действие: галочка с анимацией

---

## 9. Адаптивность

### Desktop (> 1280px)
- Полная версия интерфейса
- Таблицы со всеми колонками
- Сайдбары и панели

### Tablet (768px - 1279px)
- Уменьшенные отступы
- Некоторые колонки таблиц скрыты
- Навигация может быть компактнее

### Mobile (< 768px)
*Примечание: первая версия не фокусируется на mobile, но базовая читаемость должна быть*
- Таблицы превращаются в карточки
- Стековое расположение элементов
- Burger-меню для навигации

---

## 10. Accessibility (Доступность)

### Контрастность
- Соотношение текст/фон минимум 4.5:1 для обычного текста
- 3:1 для крупного текста

### Клавиатурная навигация
- Все интерактивные элементы доступны через Tab
- Видимый focus outline
- Escape закрывает модальные окна

### ARIA атрибуты
- aria-label для icon buttons
- aria-required для обязательных полей
- aria-invalid для полей с ошибками

### Alt текст
- Для всех изображений
- Для иконок с информацией

---

## 11. Состояния страниц

### Empty State (Пустое состояние)
Когда нет данных:
- Иконка (крупная, светло-серая)
- Заголовок: "Нет данных"
- Подзаголовок: "Добавьте первого ментора..."
- Primary кнопка для создания

### Loading State (Загрузка)
- Skeleton screen для таблиц и карточек
- Spinner для кнопок

### Error State (Ошибка)
- Иконка ошибки
- Сообщение об ошибке
- Кнопка "Попробовать снова"

## 13. Дополнительные рекомендации

### Визуальная иерархия
1. Самое важное - крупнее, контрастнее, выше
2. Группировка связанных элементов
3. Достаточно whitespace (воздуха)

### Feedback (Обратная связь)
- Загрузка: показывать спиннер
- Успех: показывать зеленое уведомление
- Ошибка: четкое сообщение, что не так
- Изменения: подсветка измененных полей

### Консистентность
- Одинаковые отступы повсюду
- Единый стиль кнопок
- Единый стиль форм
- Единые цвета для статусов

### Производительность дизайна
- Минимум внешних шрифтов (1-2)
- Оптимизированные изображения
- CSS-анимации вместо JavaScript где возможно
