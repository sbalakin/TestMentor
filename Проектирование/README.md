# Проектирование системы управления менторами

## О проекте

Данная папка содержит полное техническое задание для разработки веб-системы управления менторами. Система предназначена для учета времени работы специалистов, оказывающих услуги компании, и автоматической генерации актов выполненных работ.

## Основные функции системы

### ✅ CRUD менторов
- Создание профиля ментора с полной информацией
- Просмотр детальной информации и статистики
- Редактирование данных ментора
- Удаление или деактивация ментора

### ⏱️ Учет времени работы
- Добавление записей о выполненной работе
- Указание часов, типа работы, описания
- Автоматический расчет стоимости
- Просмотр и фильтрация всех записей
- Редактирование и удаление записей

### 📄 Генерация актов
- Формирование акта выполненных работ за период
- Выбор записей для включения в акт
- Автоматический расчет итогов
- Генерация PDF документа
- Сумма прописью на русском языке
- Архив всех сформированных актов

### 📊 Статистика и аналитика
- Общая статистика по всем менторам
- Детальная статистика по каждому ментору
- Фильтрация и сортировка данных
- Экспорт данных в Excel/CSV
- Графики и визуализация (опционально)

## Технологический стек

### Frontend
- **HTML5** - структура страниц
- **CSS3** - современный дизайн и адаптивность
- **JavaScript (ES6+)** - логика и интерактивность

### Библиотеки
- **jsPDF** или **pdfmake** - генерация PDF документов
- **SheetJS (xlsx)** - экспорт в Excel
- **Chart.js** (опционально) - графики и диаграммы

### Хранение данных
- **LocalStorage** - клиентское хранилище данных (первая версия)
- Возможность экспорта/импорта для резервных копий

## Критерии успеха

### Функциональные критерии
✅ Все CRUD операции работают корректно  
✅ Акты генерируются в правильном формате  
✅ Данные сохраняются между сеансами  
✅ Статистика отображает корректные значения  
✅ Система работает во всех целевых браузерах  

### Бизнес-критерии
✅ Формирование акта занимает не более 3 минут  
✅ Система экономит минимум 2 часа в неделю  
✅ Интерфейс понятен без обучения  
✅ Все данные о менторах в одном месте  
✅ Пользователи довольны удобством работы
