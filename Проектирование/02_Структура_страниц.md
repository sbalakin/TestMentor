# Структура страниц сайта

## Общая архитектура

Сайт состоит из отдельных HTML-страниц, каждая из которых отвечает за свою функциональность.

```
Сайт управления менторами
│
├── index.html              - Главная страница со списком всех менторов и статистикой
├── create-mentor.html      - Создание нового ментора
├── view-mentor.html        - Просмотр профиля ментора
├── edit-mentor.html        - Редактирование ментора
├── add-work.html           - Добавление записи о работе
├── view-works.html         - Просмотр всех записей о работах
├── generate-report.html    - Генерация акта выполненных работ
├── reports-archive.html    - Архив сформированных актов
└── settings.html           - Настройки системы
```

## Детальное описание страниц

### 1. index.html - Главная страница

**Назначение**: Центральная страница системы с общим обзором всех менторов и ключевой статистикой

**Основные элементы**:

#### Шапка сайта (Header)
- Логотип/Название системы: "Система управления менторами"
- Главное меню навигации:
  - Главная (активная)
  - Добавить работу
  - Все записи
  - Архив актов
  - Настройки

#### Блок статистики (Dashboard)
- Карточки с ключевыми показателями:
  - **Всего менторов**: общее количество
  - **Активных менторов**: количество менторов со статусом "Активный"
  - **Часов в этом месяце**: суммарное время работы всех менторов за текущий месяц
  - **Сумма за месяц**: общая сумма к выплате за текущий месяц

#### Панель действий
- Кнопка "Добавить ментора" (primary action)
- Кнопка "Добавить работу"
- Поле поиска по менторам

#### Таблица менторов
**Колонки**:
- № (порядковый номер)
- ФИО (с аватаром/иконкой)
- Специализация
- Ставка (руб/час)
- Часов в месяце
- К выплате (за месяц)
- Статус (бадж: Активный/Неактивный)
- Действия (кнопки)

**Действия в строке**:
- Просмотр профиля (иконка глаза)
- Редактировать (иконка карандаша)
- Добавить работу (иконка плюса)
- Сформировать акт (иконка документа)
- Удалить (иконка корзины)

**Функциональность таблицы**:
- Сортировка по столбцам (клик на заголовок)
- Фильтр по статусу (активные/все/неактивные)
- Фильтр по специализации
- Поиск по ФИО

#### Футер (Footer)
- Copyright
- Версия системы
- Ссылка на экспорт данных

**Сценарии использования**:
1. Администратор заходит на главную и видит общую картину
2. Может быстро найти нужного ментора через поиск
3. Может выполнить быстрое действие прямо из таблицы
4. Видит актуальную статистику за текущий месяц

### 2. create-mentor.html - Создание ментора

**Назначение**: Страница с формой для добавления нового ментора в систему

**Основные элементы**:

#### Заголовок страницы
- Название: "Добавить нового ментора"
- Кнопка "Назад к списку" (возврат на главную)

#### Форма создания ментора

**Блок 1: Личная информация**
- **ФИО** (обязательное поле)
  - Текстовое поле
  - Placeholder: "Иванов Иван Иванович"
  - Валидация: не менее 2 слов
  
- **Email** (обязательное поле)
  - Email поле
  - Placeholder: "mentor@example.com"
  - Валидация: корректный формат email, уникальность
  
- **Телефон** (опциональное)
  - Телефонное поле с маской
  - Placeholder: "+7 (999) 999-99-99"
  
- **Фото/Аватар** (опциональное)
  - Загрузка изображения или выбор иконки по умолчанию

**Блок 2: Профессиональная информация**
- **Специализация** (обязательное поле)
  - Выпадающий список:
    - Обучение/Менторство
    - Разработка ботов
    - Веб-разработка
    - Дизайн
    - Консультации
    - Другое (с полем для ввода)
  
- **Ставка за час работы** (обязательное поле)
  - Числовое поле
  - Placeholder: "1000"
  - Единица измерения: "руб."
  - Валидация: положительное число
  
- **Дата начала сотрудничества** (обязательное поле)
  - Datepicker
  - По умолчанию: текущая дата
  
- **Статус** (обязательное поле)
  - Радио-кнопки: Активный / Неактивный
  - По умолчанию: Активный

**Блок 3: Документы и реквизиты**
- **Паспортные данные / ИНН**
  - Текстовое поле
  - Для формирования актов
  
- **Банковские реквизиты** (опциональное)
  - Многострочное текстовое поле
  - Placeholder: "Номер счета, БИК, название банка"

**Блок 4: Дополнительная информация**
- **Заметки** (опциональное)
  - Многострочное текстовое поле
  - Placeholder: "Дополнительная информация о менторе"

#### Кнопки действий
- **Сохранить** (primary button)
  - Валидация формы
  - Сохранение в базу
  - Перенаправление на страницу просмотра созданного ментора
  
- **Сохранить и добавить еще** (secondary button)
  - Сохранение
  - Очистка формы для нового ментора
  
- **Отмена**
  - Возврат на главную страницу
  - Подтверждение при наличии несохраненных данных

**Валидация**:
- Подсветка ошибочных полей красным
- Сообщения об ошибках под полями
- Блокировка кнопки "Сохранить" при незаполненных обязательных полях
- Общее сообщение об успехе после сохранения

### 3. view-mentor.html - Просмотр профиля ментора

**Назначение**: Детальная страница с полной информацией о менторе и его статистикой

**Параметры URL**: `?id=123` (ID ментора)

**Основные элементы**:

#### Шапка профиля
- Фото/аватар ментора (слева)
- ФИО (крупный заголовок)
- Специализация (подзаголовок)
- Статус (бадж)
- Кнопки действий (справа):
  - Редактировать
  - Добавить работу
  - Сформировать акт
  - Удалить

#### Блок "Контактная информация"
- Email (с иконкой почты)
- Телефон (с иконкой телефона)
- Дата начала сотрудничества
- Ставка за час

#### Блок "Статистика"
Карточки с показателями:
- **Всего отработано часов**: общее количество за все время
- **Всего выплачено**: общая сумма за все время
- **Среднее часов в месяц**: среднее значение
- **Последняя активность**: дата последней записи о работе

#### График активности
- График количества отработанных часов по месяцам
- За последние 6-12 месяцев
- Столбчатая диаграмма

#### Блок "Последние работы"
Таблица с последними 10 записями о работе:
- Дата
- Количество часов
- Описание работы
- Сумма
- Кнопка "Смотреть все работы" (переход на filtered view-works.html)

#### Блок "Сформированные акты"
Список последних актов:
- Дата акта
- Период (месяц/год)
- Количество часов
- Сумма
- Кнопка "Скачать PDF"
- Кнопка "Смотреть все акты" (переход на filtered reports-archive.html)

#### Блок "Документы и реквизиты"
- Паспортные данные / ИНН
- Банковские реквизиты
- (скрываемый блок, раскрывается по клику)

#### Блок "Заметки"
- Дополнительная информация о менторе
- (если есть)

### 4. edit-mentor.html - Редактирование ментора

**Назначение**: Страница для изменения данных существующего ментора

**Параметры URL**: `?id=123` (ID ментора)

**Основные элементы**:

#### Заголовок страницы
- Название: "Редактирование ментора: [ФИО]"
- Кнопка "Назад к профилю"

#### Форма редактирования
- Полностью аналогична форме создания (create-mentor.html)
- Все поля предзаполнены текущими значениями
- ID ментора передается скрытым полем

#### Дополнительные элементы
- Информационное сообщение: "Последнее изменение: [дата и время]"
- Возможность отменить изменения

#### Кнопки действий
- **Сохранить изменения** (primary button)
  - Валидация
  - Обновление данных
  - Перенаправление на страницу просмотра ментора
  
- **Отмена**
  - Возврат к профилю без сохранения
  - Подтверждение при наличии изменений

**Особенности**:
- Нельзя изменить ID ментора
- При изменении ставки показывается предупреждение, что это не влияет на уже существующие записи о работах
- Валидация аналогична созданию

### 5. add-work.html - Добавление записи о работе

**Назначение**: Страница для внесения информации о выполненной работе

**Параметры URL**: `?mentor_id=123` (опциональный, если переход с профиля ментора)

**Основные элементы**:

#### Заголовок страницы
- Название: "Добавить запись о работе"
- Кнопка "Назад"

#### Форма добавления работы

**Блок 1: Основная информация**
- **Выбор ментора** (обязательное)
  - Выпадающий список с поиском
  - Показывает ФИО и специализацию
  - Предзаполнен, если пришли с профиля ментора
  - При выборе отображается текущая ставка ментора

- **Дата работы** (обязательное)
  - Datepicker
  - По умолчанию: текущая дата
  - Валидация: не может быть в будущем

- **Количество часов** (обязательное)
  - Числовое поле с шагом 0.5
  - Placeholder: "8"
  - Валидация: от 0.5 до 24
  - Подсказка: "Можно указать дробное значение, например 2.5"

**Блок 2: Описание работы**
- **Тип работы** (обязательное)
  - Выпадающий список:
    - Обучение/Менторство
    - Разработка
    - Консультация
    - Код-ревью
    - Документация
    - Встреча/Планирование
    - Другое

- **Проект/Задача** (опциональное)
  - Текстовое поле
  - Placeholder: "Разработка Telegram-бота для поддержки"
  - Для группировки работ по проектам

- **Описание** (обязательное)
  - Многострочное текстовое поле (textarea)
  - Placeholder: "Подробное описание выполненной работы..."
  - Минимум 10 символов
  - Счетчик символов

**Блок 3: Стоимость**
- **Ставка** (автозаполнение)
  - Берется из профиля ментора
  - Можно изменить для конкретной записи
  - Числовое поле

- **Итоговая сумма** (автоматический расчет)
  - Формула: Часы × Ставка
  - Отображается крупно
  - Пересчитывается при изменении часов или ставки
  - Можно редактировать вручную (на случай скидок/наценок)

**Блок 4: Дополнительно**
- **Статус оплаты**
  - Чекбокс: "Оплачено"
  - По умолчанию: не оплачено

- **Заметки** (опциональное)
  - Текстовое поле
  - Для внутренних комментариев

#### Предпросмотр
Карточка с суммарной информацией:
- Ментор: [ФИО]
- Дата: [дата]
- Часов: [количество]
- Сумма: [сумма] руб.

#### Кнопки действий
- **Сохранить** (primary button)
- **Сохранить и добавить еще**
- **Отмена**

**Дополнительные функции**:
- Возможность добавить несколько записей подряд
- Кнопка "Копировать последнюю запись" для быстрого добавления похожей работы
- Шаблоны для частых задач (сохраненные описания)

### 6. view-works.html - Просмотр всех записей о работах

**Назначение**: Страница со всеми записями о выполненных работах с фильтрами и сортировкой

**Основные элементы**:

#### Заголовок страницы
- Название: "Все записи о работах"
- Счетчик: "Всего записей: [количество]"

#### Панель фильтров
- **Ментор**
  - Мультиселект для выбора одного или нескольких менторов
  - Опция "Все менторы"

- **Период**
  - Быстрые фильтры: Сегодня / Неделя / Месяц / Год
  - Произвольный период: Datepicker с "от" и "до"

- **Тип работы**
  - Чекбоксы для выбора типов
  - Опция "Все типы"

- **Статус оплаты**
  - Радио: Все / Оплачено / Не оплачено

- **Проект**
  - Выпадающий список с проектами
  - Автозаполнение из существующих записей

- Кнопки:
  - **Применить фильтры**
  - **Сбросить фильтры**

#### Сводка по фильтру
Карточки с итогами по отфильтрованным данным:
- Всего записей
- Общее количество часов
- Общая сумма
- Не оплачено

#### Таблица записей

**Колонки**:
- Дата (сортируемая)
- Ментор (с фото/иконкой)
- Проект
- Тип работы
- Часы (сортируемая)
- Ставка
- Сумма (сортируемая)
- Оплачено (иконка галочки или креста)
- Действия

**Действия в строке**:
- Просмотр подробностей (модальное окно)
- Редактировать
- Удалить
- Отметить как оплачено/не оплачено

**Функциональность**:
- Пагинация (20-50 записей на страницу)
- Сортировка по любой колонке
- Массовое выделение записей (чекбоксы)
- Массовые операции:
  - Отметить как оплачено
  - Удалить выбранные
  - Экспорт в Excel

#### Модальное окно "Подробности записи"
При клике на запись открывается модальное окно с полной информацией:
- Все поля записи
- Кнопки "Редактировать" и "Закрыть"

#### Панель экспорта
- Кнопка "Экспорт в Excel"
- Кнопка "Экспорт в CSV"
- Кнопка "Печать"

### 7. generate-report.html - Генерация акта выполненных работ

**Назначение**: Страница для формирования официального акта выполненных работ

**Основные элементы**:

#### Заголовок
- Название: "Формирование акта выполненных работ"

#### Шаг 1: Параметры акта

**Форма выбора параметров**:
- **Ментор** (обязательное)
  - Выпадающий список
  - Автопоиск

- **Период** (обязательное)
  - Выбор месяца и года
  - Или произвольный диапазон дат

- **Номер акта** (обязательное)
  - Текстовое поле
  - Автогенерация: "№[номер]/[месяц]-[год]"
  - Можно редактировать

- **Дата составления акта** (обязательное)
  - Datepicker
  - По умолчанию: текущая дата

Кнопка "Далее" → переход к шагу 2

#### Шаг 2: Выбор работ для включения в акт

**Автоматически подгруженные записи**:
- Таблица всех работ выбранного ментора за указанный период
- Колонки: Дата, Тип работы, Описание, Часы, Сумма, Включить (чекбокс)
- Все чекбоксы по умолчанию отмечены
- Возможность исключить отдельные записи

**Сводка**:
- Выбрано записей: [количество]
- Всего часов: [сумма часов]
- Общая сумма: [сумма] руб.

Кнопки:
- **Назад** → возврат к шагу 1
- **Предпросмотр** → переход к шагу 3

#### Шаг 3: Предпросмотр акта

**Область предпросмотра**:
Отображение акта в формате, максимально близком к итоговому PDF:

[Название организации]

в лице [должность] [ФИО]

ИСПОЛНИТЕЛЬ:

Адрес: [адрес]
Телефон: [телефон], Email: [email]

Количество часов: [общее количество часов]

═══════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════

- **Редактировать** → возврат к шагу 2
- **Скачать PDF** → генерация и скачивание PDF файла
- **Печать** → открытие диалога печати
- **Отправить на email** (опционально, для будущих версий)

#### После генерации
- Сообщение об успехе
- Акт сохранен в архив
- Кнопки:
  - Сформировать еще один акт
  - Перейти к архиву актов
  - Вернуться к профилю ментора

### 8. reports-archive.html - Архив актов

**Назначение**: Хранилище всех сформированных актов с возможностью повторного скачивания

**Основные элементы**:

#### Заголовок
- Название: "Архив актов выполненных работ"
- Счетчик: "Всего актов: [количество]"

#### Панель фильтров
- **Ментор**: выпадающий список
- **Период**: выбор месяца/года или диапазона
