## 1. ФИЛОСОФИЯ ДИЗАЙНА

### Принципы

**Комфорт глаз**
- Темная тема снижает нагрузку на глаза при длительной работе
- Мягкие контрасты без резких переходов
- Отсутствие чисто черного (#000000) и чисто белого (#FFFFFF)

**Современность**
- Использование градиентов и теней для создания глубины
- Плавные переходы между состояниями
- Минималистичный но элегантный интерфейс

**Консистентность**
- Единая цветовая схема на всех страницах
- Повторяющиеся паттерны взаимодействия
- Предсказуемое поведение элементов

**Профессионализм**
- Деловой стиль без излишней игривости
- Четкая иерархия информации
- Акцент на функциональность

**Цвета**
- Используйте только цвета из палитры
- Не создавайте новые оттенки без необходимости
- Проверяйте контрастность перед использованием

- Всегда кратны 4px
- Используйте Spacing Scale
- Больше воздуха между секциями

**Типографика**
- Не более 3-4 размеров на странице
- Четкая иерархия: H1 → H2 → H3
- Ограничьте длину строк (60-80 символов)

**Компоненты**
- Переиспользуйте существующие
- Новый компонент = крайняя необходимость
- Документируйте изменения

### 15.2 ДЛЯ РАЗРАБОТЧИКОВ

**CSS переменные**
- Используйте CSS Custom Properties
- Не хардкодьте цвета
- Наследуйте от базовых стилей

**Анимации**
- Используйте transform вместо left/top
- Предпочитайте opacity вместо display
- Добавляйте will-change для сложных анимаций

**Доступность**
- Всегда добавляйте aria-атрибуты
- Проверяйте клавиатурную навигацию
- Тестируйте со screen readers

**Производительность**
- Минимизируйте repaint и reflow
- Используйте CSS вместо JS где возможно
- Debounce для частых событий (scroll, resize)

### Ключевые принципы:

✅ **Темная тема по умолчанию** - комфорт для глаз  
✅ **Модульность** - легко расширять и поддерживать  
✅ **Доступность** - WCAG 2.1 Level AA  
✅ **Производительность** - оптимизированные анимации  
✅ **Консистентность** - единый язык дизайна
